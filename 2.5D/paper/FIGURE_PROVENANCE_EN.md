# Figure provenance for the English LaTeX manuscript

The English Overleaf package contains only figures rendered from the project's
released data and actual benchmark outputs. No figure was generated by GenAI.

| File in the ZIP | Source | Production method |
|---|---|---|
| `figures/terrain_triplet_001.png` | Fifteen files matching `dataset_5010_v1/images/terrain/<family>/terrain_<family>_001_<difficulty>.png` | Each panel is a pipeline-rendered image of its corresponding JSON map. `make_figure1_options.sh` and `make_figure1_options.m` only crop repeated margins, titles, and legends and arrange the panels in a 5 × 3 grid with shared English labels. They do not modify terrain data, blocked regions, or Start--Goal coordinates. |
| `figures/dataset_difficulty_overview.png` | `dataset_5010_v1/metadata/benchmark_results/figures/dataset_difficulty_overview.png` | Produced by `analyze_25d_benchmark_results.py` from metadata for all 5,010 maps. |
| Six files matching `figures/*_mountain_hard.png` | `dataset_5010_v1/images/paths/mountain/terrain_mountain_001_hard_<planner>.png` | Actual outputs from BFS, Dijkstra, A*, PRM, RRT-Connect, and RRT* on one map and a shared Start--Goal task, rendered by the project pipeline. |
| Three files matching `figures/analysis_*_hard.png` | `dataset_5010_v1/images/analysis/<family>/terrain_<family>_001_hard_analysis.png` | Actual analysis products for `smooth_obstacles`, `rugged`, and `plateau`, showing elevation, traversability cost, and blocking causes. |

The eleven PNG files are assembled into four manuscript figures. The directory
tree is written directly in a LaTeX `verbatim` environment and is not an image.
